# game-of-cores

Signs you up for [Game of Cores](https://gameofcores.com) from the chat and connects its MCP server.

- `/game-of-cores:sign-up [email] [invite link]`: we email you an 8-digit code and a Sign in button; paste the code
  or press the button, and Claude Code is connected, signed in, with the invite's credits in your account.
- The `play` skill: when to sign up, and how to play once connected (`docs`, `seats`, `buy_seat`, `deploy`).

The steps come from the server at https://gameofcores.com/mcp/setup. Privacy: https://gameofcores.com/privacy.
